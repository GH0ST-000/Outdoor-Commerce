# Conventional Commits
#
# Format: <type>[optional scope]: <description>
#
# Types commonly used in this repository:
#   feat     A new user-facing capability
#   fix      A bug fix
#   test     Adding or correcting tests
#   docs     Documentation only
#   chore    Tooling, dependency, or environment maintenance
#   refactor Code change that neither fixes a bug nor adds a feature
#   perf     Performance improvement
#   ci       Continuous integration configuration
#
# Examples:
#   feat: add product catalog
#   fix: prevent duplicate order creation
#   test: cover inventory reservation
#   docs: document local setup
#   chore: configure development environment
#
# Breaking changes: append "!" after the type/scope, or add a BREAKING CHANGE
# footer. Keep subject lines imperative and under ~72 characters.
